# FlowInbox AI — Frontend Application

The web client for **FlowInbox AI**, built with React 18, Vite, Tailwind CSS, Framer Motion, and Lucide Icons.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:3000` or `http://localhost:5173` in your browser.

---

## 📦 Production Build

To build static minified assets served via Nginx:
```bash
npm run build
```
The output will be generated in `dist/`.
